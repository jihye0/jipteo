# 집터

생애 첫 집을 사려는 사람을 위한 순서형 도우미. 예산 → 후보 찾기 → 지도·동선 → 임장 기록·비교, 그리고 정책 정리.

- 사이트: https://jihye0.github.io/jipteo/
- 저장: 입력값·핀·임장 기록은 브라우저 저장소(localStorage)에만 남습니다.

## 페이지

| 파일 | 역할 |
| --- | --- |
| `index.html` | 내 예산. 현금·소득·상황을 넣으면 LTV·DSR·주담대 총액 한도와 취득세·중개보수를 반영해 살 수 있는 집값 상한을 계산. 정책대출 해당 여부 표시. |
| `find.html` | 후보 찾기. 서울+경기(또는 인천) 실거래가·단지 정보·전세를 합쳐 예산 안의 평형이 있는 아파트를 추림. 주상복합 추정 제외(이름 또는 1~2개 동 고층형), 재건축·재개발 추진 단지 필터, 두 사람 직장 기준 거리·어림 시간, "자세히"로 평형별 매매·전세·전세가율·갭·평당가, 역·초등학교 거리, 초보용 해석. "핀으로 담기". 급지(구·시 평당가 순위)·동 순위 칩과 급지/역 거리/1년 거래 필터, "묶음: 상급지 작은 단지"(급지 10위 안·300세대 이상·역 도보 10분·거래 10건 이상·전세가율 50% 이상·급지순) 버튼. |
| `map.html` | 지도·핀. 카카오맵(키 없으면 OpenStreetMap), 핀 상태·순서, '임장 예정' 동선, 직장 위치 표시와 핀별 출퇴근 거리, 공공데이터 단지 정보 자동 채움. |

| `visit.html` | 임장 체크리스트(7개 항목, 35점)·기록·비교표(출퇴근 열 포함), 임장 가이드. |
| `policy.html` | 2026-10-27 기준 규정. 세 줄 요약 → 내 조건(예산 입력값 기준) → 항목별 핵심 숫자·짧은 요점, 자세한 근거와 출처는 접힘. 취득세·중개보수 예시 표는 `JT.P`로 계산. |
| `watch.html` | 관심 단지. 핀으로 담은 단지의 월별 매매·전세 중앙값 그래프(`data/history/<시도>/<시군구>.json`), 첫 기록 대비 변화, 내 예산과 비교. 구글 로그인 상태 표시(허용 계정만 데이터 연결). |

| `terms.html` | 집 사는 순서 6단계와 용어 사전(50여 개, 검색·분류). 다른 페이지의 `<dfn data-t="키">` 낱말을 누르면 같은 설명이 팝오버로 뜸. |

## 데이터 (`data/`)

- `apt-<시도>.json`: 한국부동산원 「공동주택 단지 식별정보_기본정보」(공공데이터포털 15106861, 2026-08-31 기준)에서 아파트(단지종류 1) 46,981단지. 행 = `[단지명, 시군구·동 키, 지번, 세대수, 동수, 사용승인년도, 단지종류, 도로명주소]`. 경기의 "성남시 분당구"는 원자료대로 "성남분당구"로 적혀 있음.
- `price-<시도>.json`: 국토교통부 실거래가 공개시스템 아파트 매매(2025-10-28 ~ 2026-10-27, 해제 거래 제외)를 단지·전용면적(정수 반올림)별로 요약. 행 = `[시군구·동 키, 지번, 단지명, 건축년도, [[면적, 거래수, 중앙값, 최저, 최고, 최근계약년월], ...], [위도, 경도], [가까운 역, 노선, 거리m, 가까운 초등학교, 거리m] 또는 null, (있으면) [정비사업 단계, 유형, 구역명, 공급예정세대]]`. 서울·경기·인천. 좌표는 `tools/geocode.html`, 역·학교는 `tools/near.html`(카카오 장소 검색, 역 1.5km·초등학교 1km 안)로 만든 것. 정비사업은 국토교통부 「전국 도시정비사업 통합 데이터」(data.go.kr 15160169, 2026-05-18 기준)에서 같은 시군구의 재건축 구역명과 단지명이 맞는 것만 붙임(재개발·단독주택 재건축은 이름이 똑같을 때만).
- `jeonse-<시도>.json`: 같은 기간 아파트 전세(월세 제외, 보증금 기준)를 단지·전용면적별로 요약. 행 = `[시군구·동 키, 지번, 단지명, 건축년도, [[면적, 거래수, 중앙값(신규 계약 우선), 최근계약년월, 신규 건수], ...]]`. 후보 찾기의 전세가율·갭은 이 값 ÷ 매매 중앙값.

- `grade.json`: 급지. `scripts/build_grade.py`가 `price-*.json`에서 전용 40~140㎡ 평형의 "중앙값 ÷ 전용면적"을 거래 수만큼 모아(평형당 최대 30건) 구·시별 중앙값을 내고 서울·경기·인천 구·시(경기는 구 단위)를 평당가 내림차순으로 줄 세운 것. `sgg["<시도>|<구>"] = [순위, 전용 평당가(만원), 표본]`, `dong["<시도>|<동 키>"] = [구 안 순위, 평당가, 표본, 구 안 동 수]` (표본 20 미만 동은 제외). 공식 등급이 아니라 시장 가격 순위이며 매달 갱신 때 다시 계산된다.

- `mixed.json`: 손으로 확인한 주상복합 목록(공공데이터에 구분이 없음). 키 `<시도>|<동 키>|<지번>`, 값 `[단지명, 근거]`. 후보 찾기에서 추정 규칙(이름·1~2개 동 고층형)과 함께 '주상복합 제외'에 쓰이고, 목록 칩에 '추정' 없이 표시된다. 네이버 지도에서 '주상복합'으로 나오는 단지를 찾으면 여기에 추가.

## 갱신

`.github/workflows/update-data.yml`이 매월 2일 06:00(KST)에 `scripts/update_data.py`를 돌려 공공데이터포털 실거래가 API(아파트 매매·전월세, 서울·경기·인천 79개 시군구)로 최근 2개월을 다시 받아 `data/history/`에 쌓고 `price-*.json`·`jeonse-*.json`을 최근 12개월로 다시 만들고, 끝에 `scripts/build_grade.py`로 `grade.json`(급지)을 다시 계산한다. 저장소 Secrets의 `DATA_GO_KR_KEY`를 쓴다. 손으로 돌리려면 Actions 탭에서 workflow_dispatch(개월 수 입력). 좌표·역·학교·정비사업은 기존 행에서 보존되고, 새로 생긴 단지는 `tools/geocode.html`·`tools/near.html`로 채운다.


실거래 요약을 다시 만들려면 실거래가 공개시스템에서 시도별 CSV(분기 단위)를 받아 같은 형식으로 집계하고, `tools/geocode.html`로 좌표를 다시 붙입니다. 출퇴근 시간은 직선거리로 어림한 값(약 12분 + 3.4분/km)이며 정확한 값은 칩의 카카오맵 길찾기 링크로 확인합니다. 규정 수치는 `assets/app.js`의 `JT.P`와 `policy.html`을 함께 고칩니다.
