# 집터

부동산 임장(현장 답사) 도우미. 후보 단지를 지도에 핀으로 찍고, 현장 체크리스트로 점수를 매겨 단지끼리 비교합니다.

- 사이트: https://jihye0.github.io/jipteo/
- 지도: 카카오맵 JavaScript 키를 페이지의 '지도 설정'에 넣으면 카카오맵과 단지명 검색이 켜집니다. 키가 없으면 OpenStreetMap으로 동작합니다.
- 저장: 기록과 핀은 브라우저 저장소(localStorage)에만 남습니다.
- 단지 정보: `data/apt-*.json`은 한국부동산원 「공동주택 단지 식별정보_기본정보」(공공데이터포털, 2026-08-31 기준)에서 아파트(단지종류 1) 46,981단지를 추려 시도별로 나눈 것입니다. 필드는 [단지명, 시군구·동 키, 지번, 세대수, 동수, 사용승인년도, 단지종류, 도로명주소]. 핀을 찍을 때 주소와 단지명으로 찾아 세대수·동수·준공년도를 자동으로 채웁니다.

파일 하나(`index.html`)로 동작합니다.
