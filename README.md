# 집터

생애 첫 집을 사려는 사람을 위한 순서형 도우미. 예산 → 후보 찾기 → 지도·동선 → 임장 기록·비교, 그리고 정책 정리.

- 사이트: https://jihye0.github.io/jipteo/
- 저장: 입력값·핀·임장 기록은 브라우저 저장소(localStorage)에만 남습니다.

## 페이지

| 파일 | 역할 |
| --- | --- |
| `index.html` | 내 예산. 현금·소득·상황을 넣으면 LTV·DSR·주담대 총액 한도와 취득세·중개보수를 반영해 살 수 있는 집값 상한을 계산. 정책대출 해당 여부 표시. |
| `find.html` | 후보 찾기. 최근 1년 실거래가와 단지 정보를 합쳐 예산 안의 평형이 있는 아파트를 추림. 두 사람 직장 기준 직선거리·대중교통 어림 시간, 거리 필터·정렬. "핀으로 담기". |
| `map.html` | 지도·핀. 카카오맵(키 없으면 OpenStreetMap), 핀 상태·순서, '임장 예정' 동선, 직장 위치 표시와 핀별 출퇴근 거리, 공공데이터 단지 정보 자동 채움. |
| `visit.html` | 임장 체크리스트(7개 항목, 35점)·기록·비교표(출퇴근 열 포함), 임장 가이드. |
| `policy.html` | 2026-10-27 기준 LTV·DSR·규제지역·정책대출·취득세·중개보수 정리(출처 포함). |
| `terms.html` | 집 사는 순서 6단계와 용어 사전(50여 개, 검색·분류). 다른 페이지의 `<dfn data-t="키">` 낱말을 누르면 같은 설명이 팝오버로 뜸. |
| `assets/style.css`, `assets/app.js`, `assets/terms.js` | 공통 스타일, 저장소, 데이터 로더, 예산 계산, 출퇴근 계산(직선거리 → 어림 시간), 카카오 SDK 로더, 규정 파라미터(`JT.P`), 용어 데이터. |
| `tools/geocode.html` | 관리용. 실거래 요약의 단지마다 카카오 주소 검색으로 좌표를 만들어 `window.GEO.out`에 쌓음(사이트 도메인에서만 동작). |

## 데이터 (`data/`)

- `apt-<시도>.json`: 한국부동산원 「공동주택 단지 식별정보_기본정보」(공공데이터포털 15106861, 2026-08-31 기준)에서 아파트(단지종류 1) 46,981단지. 행 = `[단지명, 시군구·동 키, 지번, 세대수, 동수, 사용승인년도, 단지종류, 도로명주소]`. 경기의 "성남시 분당구"는 원자료대로 "성남분당구"로 적혀 있음.
- `price-<시도>.json`: 국토교통부 실거래가 공개시스템 아파트 매매(2025-10-28 ~ 2026-10-27, 해제 거래 제외)를 단지·전용면적(정수 반올림)별로 요약. 행 = `[시군구·동 키, 지번, 단지명, 건축년도, [[면적, 거래수, 중앙값, 최저, 최고, 최근계약년월], ...], [위도, 경도(, 1=동 중심 대략값)]]`. 서울·경기·인천 포함. 좌표는 `tools/geocode.html`(카카오 주소 검색)로 만든 것.

## 갱신

실거래 요약을 다시 만들려면 실거래가 공개시스템에서 시도별 CSV(분기 단위)를 받아 같은 형식으로 집계하고, `tools/geocode.html`로 좌표를 다시 붙입니다. 출퇴근 시간은 직선거리로 어림한 값(약 12분 + 3.4분/km)이며 정확한 값은 칩의 카카오맵 길찾기 링크로 확인합니다. 규정 수치는 `assets/app.js`의 `JT.P`와 `policy.html`을 함께 고칩니다.
